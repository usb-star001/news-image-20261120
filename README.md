# news-image-20261120 — The World in One Day

One image summing up the world's news of Friday 20 November 2026: 36 verified
stories from that day across 6 regions, with a world map, a big-numbers strip,
and a DATE CHECK box listing the big stories deliberately left out because they
were first reported on 19 November or earlier.

The image is rendered programmatically (Python PIL, real text, original flat
drawings) and copied to `/output/entry.png` by `main.ts` (Node 22, standard
library only, deterministic — both runs write identical bytes).
